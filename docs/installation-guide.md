# Installation Guide

This guide explains how to assemble a PC and prepare it for use.

## Preparation

Before assembly:

- clear a clean work surface
- keep tools ready: screwdriver, zip ties, thermal paste if needed
- read the motherboard and case manuals
- verify the parts list
- ground yourself to avoid static discharge

## Step 1: Install the CPU

1. Open the CPU socket retention lever.
2. Align the CPU with the socket marker.
3. Place the processor gently into the socket.
4. Lower the retention arm until it locks.
5. Apply thermal paste if the cooler does not include pre-applied paste.

## Step 2: Install the RAM

1. Open the RAM latches on the motherboard.
2. Align the notch on the memory module with the slot.
3. Press down until the latches lock into place.
4. Install RAM in the recommended slots for dual-channel setups.

## Step 3: Mount the motherboard

1. Place the motherboard standoffs in the case.
2. Align the board to the mounting holes.
3. Secure the motherboard with screws.
4. Do not overtighten screws.

## Step 4: Install storage

1. Insert NVMe drives into the M.2 slots.
2. Secure the drives with the included screw or retention mechanism.
3. For SATA drives, connect the drive to the motherboard and power supply.

## Step 5: Install the power supply

1. Place the PSU in the case according to airflow direction.
2. Secure it with screws.
3. Connect the 24-pin motherboard cable.
4. Connect CPU power, GPU power, and peripheral power leads.

## Step 6: Install the CPU cooler

1. Mount the bracket or backplate according to the cooler instructions.
2. Apply thermal paste if needed.
3. Attach the cooler and tighten evenly.
4. Plug the cooler fan into the motherboard header.

## Step 7: Install the GPU

1. Insert the graphics card into the top-most PCIe x16 slot.
2. Press until it clicks into place.
3. Secure the bracket to the case.
4. Connect the required PCIe power cables.

## Step 8: Connect case fans and front panel

1. Install intake and exhaust case fans.
2. Connect fan headers to the motherboard or fan controller.
3. Attach front-panel USB, audio, and power switch cables.
4. Route cables neatly to improve airflow.

## Step 9: Initial power-on check

Before sealing the case:

- double-check every cable connection
- verify that the CPU fan is powered
- confirm the memory and GPU are seated correctly
- check that the PSU is fully connected

Power on the system and watch for display output, POST, and fan activity.

## Step 10: Install the operating system

1. Prepare a bootable USB drive.
2. Enter BIOS/UEFI.
3. Set the USB as the boot device.
4. Install the OS.
5. Install chipset, graphics, and other drivers.
6. Update the system firmware and operating system patches.

## Step 11: Validate system performance

After installation:

- confirm display output and audio
- verify network and USB connectivity
- run a short stability check or benchmark
- monitor temperatures under load

## Safety notes

- Avoid forcing any connection
- Never work inside a PC while it is powered
- Handle memory and CPU carefully
- Maintain static-safe practices during assembly

## Summary

The installation process becomes much easier when done methodically. Follow each step in order, and confirm each component before moving to the next.
