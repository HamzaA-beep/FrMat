# FrMat

FrMat is a public documentation repository for building, installing, and maintaining a personal computer system. It includes a clear overview of the hardware stack, component recommendations, installation steps, and troubleshooting guidance.

## Contents

- Overview of the PC build
- Core hardware components
- Installation and assembly guide
- Troubleshooting checklist
- Maintenance and upgrade notes

## Project goals

This repository is designed to help a user:

- understand the major PC components and their roles
- choose compatible parts for a functional system
- assemble the PC safely and correctly
- install the operating system and drivers
- maintain the machine over time

## Recommended build approach

A reliable home or workstation PC usually includes:

- CPU
- motherboard
- RAM
- storage
- GPU (if needed)
- power supply
- cooling solution
- case
- operating system

## Documentation map

- `docs/overview.md` — system overview and design philosophy
- `docs/components.md` — component descriptions and compatibility notes
- `docs/installation-guide.md` — step-by-step assembly and setup process
- `docs/troubleshooting.md` — initial setup and common problems
- `docs/maintenance.md` — cleaning, upgrades, and upkeep

## Quick start

1. Review the system overview.
2. Check component compatibility.
3. Follow the assembly and installation guide.
4. Install the OS and drivers.
5. Validate the system with benchmark and stress checks.
